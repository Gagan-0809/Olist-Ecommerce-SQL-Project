# 🛒 Olist Brazilian E-Commerce Data Analysis
### Advanced MySQL Project | 50 Business Questions

## 📌 Project Overview

This project focuses on analyzing the Brazilian E-Commerce Public Dataset by Olist using **MySQL**.

Olist is a Brazilian e-commerce platform that connects small businesses with customers through an online marketplace.

The objective of this project is to extract meaningful business insights from e-commerce data by solving 50 real-world business questions using SQL.

The project demonstrates my ability to work with relational databases, perform complex queries, analyze business performance, and generate actionable insights.

---

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Identify top-performing customers and sellers.
- Understand customer purchasing behavior.
- Analyze product category performance.
- Evaluate payment methods and order trends.
- Measure seller delivery performance.
- Analyze customer retention and repeat purchases.
- Calculate monthly revenue growth.
- Identify business opportunities through SQL analysis.

---

## 🗂️ Dataset Information

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

The dataset contains information about orders, customers, products, sellers, payments, reviews and geographical locations.

### Database Tables

The project uses the following 9 tables:

| Table Name | Description |
|---|---|
| customers | Customer information |
| orders | Order details and status |
| order_items | Products purchased in each order |
| products | Product information |
| sellers | Seller information |
| order_payments | Payment information |
| order_reviews | Customer reviews |
| geolocation | Geographical information |
| product_category_name_translation | English product category translations |

## 💡 Business Problems Solved

This project contains 50 SQL business questions covering different areas of e-commerce analytics.

Some advanced analytical problems include:

1. Identifying the top 3 customers in each state.
2. Calculating monthly revenue growth using LAG().
3. Analyzing repeat customers and average days between orders.
4. Calculating seller-wise late delivery percentages.
5. Ranking product categories based on revenue contribution.
6. Segmenting customers into four spending groups using NTILE().
7. Identifying the most popular payment type in each state.
8. Analyzing customer retention within 90 days.
9. Ranking sellers within each product category.
10. Analyzing customer lifetime spending.
